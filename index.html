🖼️ Migrar imágenes locales a ImgBB

Si subiste imágenes sin tener la API key, quedan guardadas dentro del navegador. Este botón las publica en ImgBB para que estén disponibles en la nube y en cualquier dispositivo.

🚀 Guía rápida

1
Crea tu API key en ImgBBEntra a api.imgbb.com, crea una cuenta, genera la API key y pégala arriba.
2
Crea tu base de datos en FirebaseProyecto nuevo → Realtime Database → crear en modo prueba → copia la URL de la base.
3
Guarda y sincronizaPresiona "Guardar credenciales", luego "Subir todo a la nube". Si activas el auto-sync, cada cambio se guarda solo.
